# Demo media attribution: Valencia (DANA, 29-30 October 2024)

All files come from Wikimedia Commons (https://commons.wikimedia.org) and were retrieved on 2026-10-28 with the Commons API. Only CC0 and CC BY / CC BY-SA files were accepted; the licence and author are as shown on each Commons file page at retrieval time.
Photos are the Commons 1600/1920 px thumbnails downscaled to width <= 1600 px and re-encoded as JPEG (q88). Videos were converted from WebM to H.264 MP4 (max width 1280 px, audio removed) because SAM 3.1 rejects WebM.
**CC BY and CC BY-SA require attribution (author, licence, link) wherever the media is shown. CC BY-SA also requires derivatives (crops, overlays, converted copies) to be shared under the same licence.**
Coordinates: `Photo` = GPS from the Commons page; `Town` = Commons gives one town-level point for all Catarroja photos by this author (not the camera position); `-` = no coordinates on the Commons page (the demo scenario places these on a plausible street).
